# GitHub-портфолио

Профиль проверен по доступным репозиториям `HiliyItishnik`: `java-core-task-manager`,
`java-console-calculator`, `credit-payment-tracker`, `FinanceTracker` и `teamflow`.
Для карточек использованы фактические README, а не только названия проектов.

Готовый текст профиля: [profile-README.md](profile-README.md). Он показывает развитие
от Java Core к многопользовательскому backend, без заявлений о коммерческом опыте.
TeamFlow публикуется по прямому разрешению владельца после [проверки истории](publication.md).
`FinanceTracker` пока не выдвинут в основные проекты: для профиля выбраны четыре проекта
с понятной ролью и подтверждённым описанием.

Профильный README опубликован в открытом репозитории
[HiliyItishnik/HiliyItishnik](https://github.com/HiliyItishnik/HiliyItishnik)
(коммит `fdb183635ec947dec942482e2a8eda3c56fc1306`). Локальная копия текста — `profile-README.md`.
TeamFlow доступен публично: [HiliyItishnik/teamflow](https://github.com/HiliyItishnik/teamflow).
После появления сервера добавь в профиль проверенный HTTPS-адрес демонстрации.
В закреплённые репозитории подходят TeamFlow, Credit Payment Tracker и Java Core Task Manager.
Закрепление выполняется в интерфейсе профиля.

Для показа TeamFlow подготовлены [демо-сценарий](demo.md), [архитектура](architecture.md),
[тестирование](testing.md), [эксплуатация](operations.md), [измерения](performance.md)
и [развёртывание](deployment.md). В репозиторий не помещаются копии реальных БД и сессии демо.
