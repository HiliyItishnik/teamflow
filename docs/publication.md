# Публичный репозиторий

Владелец разрешил сделать TeamFlow публичным 3 ноября 2026 года.
Это открывает исходники и историю Git; работающий сервис по HTTPS требует отдельного развёртывания.

Перед публикацией проверены все доступные ветки/коммиты Gitleaks 8.30.1 с полным сокрытием
значений в отчёте. Четыре срабатывания разобраны: три UUID идемпотентности в документации
и HTTP-примере и заведомо неподписанный JWT `alg=none` с пустым payload из теста отказа доступа.
Для них в `.gitleaksignore` перечислены точные fingerprints коммита/файла/строки.
Файлы тестов и документации целиком не исключаются из проверки.

Проверка не обнаружила других секретов. Также проверено отсутствие `.env`, архивов БД
и файлов ключей в истории. Это результат автоматического сканирования и разбора срабатываний,
а не гарантия отсутствия любых конфиденциальных данных.

Новый CI-job сканирует полную историю при push/PR. Версия CLI закреплена;
официальный архив проверяется по SHA-256 из релиза Gitleaks.
Секреты, токены, реальные дампы и локальные отчёты должны оставаться вне Git.
